How to read a bench

  • Every build normalises to the same declared envelope, so the builds differ by interpretation, not by size.
  • Model names come from the bench registry. Each build also reports what its own metadata sealed at build time; the original library sealed an assistant name and no model version.
  • Review states are reported exactly as the library sealed them. A build that has not been reviewed says so; nothing here self-certifies.
  • No bench picks a winner. The differences are listed so you can judge the builds yourself.
