Method

One pipeline, repeated 1,280 times.

Each object starts with fixed dimensions and a generated reference image. The pipeline builds it in Blender, packages it as USDZ, and runs technical checks on structure, scale, bounds, and placement. Nobody reviewed the results by eye, so judge the objects yourself.

Read the full method ↗
  1. 01
    Specify

    Set the size, category, and construction constraints.

  2. 02
    Generate

    Create the reference and build the object in Blender.

  3. 03
    Package

    Export a self-contained USDZ and run structural checks.

  4. 04
    Compare

    Keep the reference and result together, mistakes included.

Use with judgment

The files are open. The results are imperfect.

The assets are available under CC BY 4.0. Credit “GenHome3D-1280 contributors” and link to the repository when redistributing or adapting them.

Automated checks cover file structure, scale, bounds, placement, textures, and checksums. They do not prove an object is correct, realistic, safe, or production-ready.
